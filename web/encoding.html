编码原理

03 / ENCODING
01

段位置 → 比特

a 是上横段，随后 b、c 为右侧，d 为下横段，e、f 为左侧，g 为中横段。bit0～bit7 依次对应 a、b、c、d、e、f、g、dp。

逻辑 1 表示点亮，0 表示熄灭。段名与器件引脚编号独立。

02

比特 → 十六进制

数字 2 点亮 a、b、d、e、g。从高位写起得到 0101 1011，每四位转换一次：

0101 10112 → 0x5B

下标 ₂ 表示二进制，不是平方；0x 表示十六进制。A～F 对应十进制 10～15。每四位二进制对应一位十六进制：0101 为 5，1011 为 B。

字符 '2' 的 ASCII 为 0x32，与显示段码不同。

03

逻辑 → 段电平

位序相同、直接驱动且没有额外反相时，共阴段电平等于逻辑段码，共阳段电平为其八位取反。

0x5B XOR 0xFF → 0xA4

XOR 是逐位异或：相同得 0，不同得 1。0xFF 的八位均为 1，与它异或会翻转每一位。C 和 JavaScript 写作 ^。

    0101 1011 （0x5B）
XOR 1111 1111 （0xFF）
  = 1010 0100 （0xA4）

专用驱动芯片还须遵循寄存器定义，位选信号单独处理。

数字 2 的逐位对应关系

每列固定对应一个段；比特权值相加：64 + 16 + 8 + 2 + 1 = 91 = 0x5B。

小数点与按位或 OR

按位或：任一输入位为 1，结果即为 1。C 与 JavaScript 写作 |。默认位序中，小数点为 bit7，段码为 0x80。

2. → 0x5B | 0x80 = 0xDB

OR 添加亮段，XOR 翻转位；添加小数点使用 OR，重复添加不会将它熄灭。
