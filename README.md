# Segment Lab · 段码实验室

段式显示技术与资源项目，提供交互式字形设计、段码转换、显示仿真、通用驱动、器件资料及开发教程，支持不同位数、段数与定制显示布局。

设计依据见 [调研记录](docs/design/research.md) 与 [网站设计](docs/design/website-design.md)。

## 当前内容

[字形与段码参考手册](web/index.html)覆盖数字、大小写字母与符号，共 66 个输入字符，支持段码交互、筛选与 CSV 下载。

## 目录

- `web/`：可独立发布的静态网站，首页为 index.html。
- `docs/`：项目架构、设计约定、教程与资料索引。
- `data/`：字符映射等可复用数据，作为网站数据的来源。
- `drivers/`：通用显示驱动及平台适配，尚未迁入实现。
- `examples/`：按平台组织的接入示例，尚无实例工程。
- `references/`：经来源与分发条件核对后的器件资料。
- `tests/`：数据、网站及后续驱动验证。
- `tools/`：生成与检查工具。
- `work/`：本地中间产物，不纳入版本管理。

## 本地预览

安装 Python 3 后，在仓库根目录执行 `python -m http.server 8000 --directory web`，打开 http://localhost:8000 。网站使用 ES 模块，须通过 HTTP 服务访问。

## 检查与发布

运行 `python tools/check_site.py` 检查字符数据及本地资源链接。

网站无需安装前端依赖或构建。GitHub Pages 部署步骤见 [部署说明](docs/deployment.md)；目前尚未部署。
