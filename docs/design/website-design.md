# Segment Lab 网站设计 v1

## 目标与范围

面向嵌入式开发者、硬件工程师与学习者，完成查字形、看亮段、转换编码和预览显示的连续操作。首期支持现有 66 项字形（含不支持项）、单段编辑、1～12 位预览、共阴/共阳编码、CSV 下载。十四段、十六段及定制布局留作扩展，不在界面上提供尚未实现的选项。

## 信息架构与视觉

采用左侧品牌导航与右侧工作区，窄屏改为顶部导航。浅灰底、白色工具面板、深色显示台、默认红色高亮段，支持颜色选择器同步修改所有预览，减少长篇正文。采用多页面架构（MPA）：index.html 为实验台，characters.html 为字符库，encoding.html 为编码原理。共享品牌、导航与样式，各页面独立入口。开发资源暂不作为页面展示。字符卡片通过 URL 字符参数进入实验台。

## 模块边界

- data/segment-character-map.csv：字形事实来源；空段码表示不支持，不能转为空白。
- tools/sync_data.py：生成网站 CSV 和 js/data/glyphs.js，禁止手动维护第二套映射。
- js/core/encoding.js：逻辑段码与电平转换、文本拆位，纯函数，无 DOM。
- js/data/layouts.js：段名称与几何布局；位数独立于段数。
- js/components/display.js：按布局和段码生成 SVG 元素，不解析文字。
- js/pages/：按实验台、字符库、编码原理分别管理页面状态与事件；components/controls.js 提供公共逐位标注。
- css/tokens.css：颜色、间距与字体变量；css/main.css：布局与组件规则。

HTML 仅含语义结构，通过 module 脚本入口装配；禁止内联样式、脚本和事件属性。

## 交互约定

点击字符载入单字实验台，段开关和编码联动。二进制采用八列网格，每列显示段名、bit 编号和值。共阳模式只改变输出段电平码，不改变亮段。文本输入的小数点附于前一位，开头点占一个空白位；连续点报错。不支持字符及超出位数明确报错，清除失效预览，避免误读旧结果。不截断、不擅自替换。所有按钮可键盘访问，状态通过 aria-live 提示。

## 扩展与维护

新段布局增加独立描述与对应字库；渲染器通过布局参数读取几何信息。位序转换和芯片协议后续独立适配，不混入 SVG。当前八位编码范围必须明确校验，后续超过 31 位采用 BigInt 或位集合，不直接扩展 JS 位移。

## 注释与格式

JavaScript 使用四空格、分号、命名函数、ES modules。导出函数写中文 JSDoc，说明参数、返回及错误；复杂分组说明原因，不逐行复述。CSS 按变量、布局、组件、响应式分组，每条声明独立一行。数据文件由工具生成并标明来源。新增行为必须核对影响的边界测试。

## 验收

自动验证数据同步、66 项映射、极性转换、单字/多位/小数点/不支持字符与溢出；检查本地资源和模块语法。浏览器核对桌面与手机宽度、键盘操作、筛选和预览。通过自动检查不等于页面视觉验收。Pages 尚未发布。

## 布局与可用性检查（2026-10-29）

实验台左右面板保持等高。左侧采用纵向 Flex 布局，预览区弹性扩展并居中，段开关与提示置底，避免空白集中于面板下方。中等宽度改为单列，窄屏开关按四列排列；编码列固定一一对应。颜色设置跨页保存，存储受限时退回本页设置。字符库补充无匹配状态及大小写十六进制前缀搜索。

自定义输出位序暂缓；当前使用固定 bit0=a 至 bit7=dp。编码原理保留进制标记、XOR 与 OR 说明。

## 导出格式

实验台提供 C 字符表、C 文本数组与 JSON 配置。位序固定为 bit0=a 至 bit7=dp，输出为所选极性的段电平码；不包含位选、反相电路和芯片命令。字符表使用 ascii/code/supported 三字段，不支持项的 code 无效，调用者须检查 supported。JSON 记录 schemaVersion、位序、极性、左右顺序、小数点和补位规则、逻辑码及输出字节。无效文本禁止下载帧或 JSON，字符表可独立导出。
